# Design: Engraphis v1.8 Team Delta Sync Client (`engraphis sync --team`)

**Status:** Approved & Implemented (All EGM Goldfish Findings Resolved)
**Repo:** `Coding-Dev-Tools/engraphis` (branch `feat/v1-8-team-delta-client`)
**Release:** Release 1 (`v1.8` - Beta-to-GA Team Memory Sync)

### EGM Goldfish Review Resolutions
- **Tombstone eviction vs soft retire:** `retire` tombstones call `service.retire(..., at=None)` (preventing clock-skew `valid_to < valid_from` errors); `unapprove` and `erase` tombstones purge local rows and vectors via `store.secure_erase_memory(..., _defer_maintenance=True)` + `engine.index.delete(...)`, running `store.run_secure_erase_maintenance()` at most once after the batch finishes.
- **Trust, dedupe, and echo-loop contract:** Pulled memories come from an authenticated Team server where a Team reviewer approved them. Each item still undergoes client-side `reject_secrets` and `assess_untrusted_payload` defense-in-depth before writing with `source="agent"`, `resolve_conflicts=False`, and `metadata={"capture_mode": "team_delta_sync", "team_memory_id": ..., "team_content_hash": ...}`. Identical `team_content_hash` is a clean no-op; changed content updates the cached copy by retiring the stale local row and storing the revision. `--propose` strictly excludes all rows carrying `team_memory_id` or `capture_mode == "team_delta_sync"`.
- **Canonical URL hygiene:** Never hardcode `https://team.engraphis.com` (which is listed in `RETIRED_RELAY_URLS` in `engraphis/config.py`). Require explicit `--team <url>` or `ENGRAPHIS_TEAM_URL`, validated via `validate_cloud_base_url()`, and require `ENGRAPHIS_TEAM_TOKEN_ORIGIN` origin match (`(scheme, hostname, effective_port)`) whenever `ENGRAPHIS_TEAM_TOKEN` is used.
- **SSRF / proxy / redirect / size hardening:** Built opener installs `urllib.request.ProxyHandler({})`, `_NoRedirectHandler` (refusing all 3xx redirects so `Authorization: Bearer` never leaks cross-origin), `PinnedHTTPSHandler()`, bounded `DEFAULT_CONNECT_TIMEOUT_SECONDS`, and a 10 MiB response cap.
- **Push scope & per-item secret isolation:** `--propose` filters strictly to active (`valid_to IS NULL`, `expired_at IS NULL`), non-quarantined (`inspection_eligible`), non-secret/non-restricted (`sensitivity NOT IN ('secret', 'restricted')`), workspace/repo/project/global scopes (excluding `session` and `user`), validates `reject_secrets` per candidate across `content`, `title`, and `repo` (preventing head-of-line blocking), and skips oversized items (`> 900_000` UTF-8 bytes).
- **Cursor atomicity, bounded state, and `--status`:** Items are applied before tombstones on every page so same-page item+tombstone pairs never resurrect. `sync_state` stores `{origin, workspace, repo, cursor, tombstone_since, last_sync_at}` under `team_delta_cursor:<hash>` so read-only `--status` can scan `team_delta_cursor:%` without requiring `--team`. `team_delta_proposed:<hash>` stores a bounded `{memory_id: content_hash}` map (max 5,000 entries) so edited memories re-propose cleanly.

## 1. Architecture & Data Flow

1. `engraphis sync --db <db> --workspace <ws> --team <url> [--repo <r>] [--propose] [--propose-source passive-hook|all] [--read-only] [--dry-run]`
2. Pull phase (`pull_team_delta`):
   - Bootstraps missing local workspace (`service.store.get_or_create_workspace`) unless `--dry-run`.
   - Paginates `POST <url>/v1/team/workspaces/<ws>/delta` with `{"cursor": ..., "tombstone_since": ..., "limit": ..., "repo": ...}`.
   - Applies approved items (with secret & poisoning defense-in-depth, `resolve_conflicts=False`), then applies tombstones (`retire` vs `unapprove`/`erase`), then persists the updated watermark in `sync_state`.
3. Optional proposal phase (`push_team_proposals`, only when `--propose` is passed and not `--read-only` / `sync_read_only()`):
   - Fails closed if workspace visibility is `"personal"` or unreadable.
   - Selects eligible local candidates not yet proposed at their current `content_hash`, validates each with `reject_secrets`, chunks batches under 50 items and 900,000 UTF-8 bytes, and POSTs `{"confirmed_shared_hosting": true, "memories": [...]}` to `/v1/team/workspaces/<ws>/propose`.

## 2. Concrete File Changes

1. `engraphis/team_delta.py`: Core transport, SSRF/redirect-safe HTTP client, delta pull, tombstone eviction, proposal batching, and SQLite watermark helpers.
2. `scripts/sync.py`: Wire `--team`, `--propose`, `--propose-source`, `--team-token` argv refusal, read-only checks, and `--status` reporting.
3. `tests/test_team_delta_client.py`: Comprehensive offline unit, adversarial security, and CLI dispatch tests.
4. `docs/benchmark-evidence/` + `BENCHMARKS.md` + `README.md` + `tests/test_benchmark_evidence.py`: Refresh SHA-256 bound offline benchmark evidence artifact.
